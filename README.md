# ui_navigasi_dasar

Project latihan Flutter untuk materi **Navigasi & Routing**.

## Materi yang dipraktikkan

- `Navigator.push` dan `Navigator.pop`
- Mengirim data lewat constructor
- Named route dan route arguments
- Mengembalikan data dari halaman tujuan
- Bottom navigation dengan `IndexedStack`

## Struktur utama

```text
lib/
  main.dart
  models/
    contact.dart
  screens/
  theme/
  widgets/
```

## Menjalankan project

```text
flutter pub get
flutter run
```

## Verifikasi

```text
flutter analyze
flutter test
```
